# 공공데이터 팩트 페이지 키트

흔한 생각을 질문으로 바꾸고, 공공데이터 원자료로 확인하고, 주제에 맞는 그림으로 보여 주는 한 장짜리 페이지를 만드는 도구와 예시입니다.

- **먼저 읽을 것:** [`HANDOFF.md`](HANDOFF.md). AI에게 일을 맡길 때도 이 문서를 읽게 하면 됩니다.
- **바로 보는 예시:** [`examples/`](examples). 브라우저로 바로 열리는 완성 페이지 6개
- **빌드 도구:** `kit/` (공통 CSS·JS, 조립, 화면·대비 점검, 템플릿 51개)
- **질문 목록:** `backlog/questions.json`, `backlog/README.md`
- **완성본:** `pages/` (아티팩트 조각 형식). **집계 스크립트와 결과:** `data/`
- **색:** `design/palette.json`

원자료 큰 파일과 `raw/` 폴더는 넣지 않았습니다. 다시 받는 방법은 각 스크립트와 `backlog/questions.json`의 `notes`에 있습니다.
디자인 점검 기준은 [impeccable](https://github.com/pbakaus/impeccable) 스킬을 씁니다.
