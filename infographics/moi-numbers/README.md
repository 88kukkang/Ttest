# 행안부가 알린 숫자

행안부 보도자료 DB의 본문·표에 실린 숫자로 만든 인포그래픽 세 장: 예산 84조 원의 쓰임, 지원금 신청 레이스, 인구감소지역 생활인구.

- `race.py`: 소비쿠폰·고유가 피해지원금 신청 현황 보도참고자료에서 신청률과 시도별 표를 읽어 `race_raw.json`을 만든다
- `build2.py`: 예산·레이스·생활인구 숫자를 모아 `data2.json`을 만든다(입력: DB 페이지 `docs.b64.txt`를 풀어 둔 `../web/docs.bin`)
- `numbers.html`: 페이지(아티팩트 조각 형식, `data2.json`을 옆에 두고 연다)
